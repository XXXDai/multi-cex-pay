后台令牌

即 CEXPAY_ADMIN_TOKEN 环境变量的值。只保存在这台浏览器里。

1 · 只读 API 凭据

只需要 读取 权限：别勾选交易、提币、划转。检测到写权限会直接拒绝启动。 建议同时开启 IP 白名单。

2 · 收款二维码

直接丢交易所 App 的收款页整张截图进来：系统会自动定位二维码、 透视校正、解出内容后重绘成标准码。不用自己裁图。

3 · 聚合收款图

把已配置的收款码拼成一张图，可以打印张贴或嵌到自己页面里。 生成后会回读校验每个码是否仍能被扫出来。
